# 🌦️ Live Weather & Analytics Dashboard

A modern, interactive **Weather Analytics Dashboard** built with **Python**, **Streamlit**, **Plotly**, **Pandas**, **SQLite**, and **Scikit-Learn**. The application provides real-time weather information, historical analytics, air quality insights, and machine learning-based forecasting through an intuitive dashboard.

---

## 🚀 Features

- 🌍 Search weather for any city
- 🌡️ Real-time weather conditions
- 📅 7-Day Weather Forecast
- ⏰ 24-Hour Forecast
- 🗺️ Interactive Weather Map
- 🌫️ Air Quality Index (AQI)
- ⚠️ Weather Alerts
- ⭐ Favorite Cities
- 📊 Weather Analytics Dashboard
- 📈 Historical Weather Trends
- 🤖 Machine Learning Forecasting
- 🌆 Compare Multiple Cities
- 📄 Export Reports
  - CSV
  - Excel
  - PDF
- 🌙 Dark & Light Theme
- 🔄 Auto Refresh
- 💾 SQLite Database Logging

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/raju5162/live-weather-dashboard.git
```

Move into the project

```bash
cd live-weather-dashboard
```

Create virtual environment

```bash
python -m venv venv
```

Activate environment

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
